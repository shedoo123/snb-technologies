# SNB Technologies — Brand Asset Package

**Tagline:** Engineering Beyond Limits.

## Identity direction
A refined minimalist technical identity built around a geometric SNB monogram, an open-corner frame, and a restrained blue/cyan accent system. The wordmark uses live SVG text so it remains easy to edit; the monogram is constructed from vector paths.

## Files
- `svg/snb-primary-transparent.svg` — primary horizontal lockup, transparent background
- `svg/snb-primary-light.svg` — primary lockup on white
- `svg/snb-primary-dark.svg` — primary lockup on midnight navy
- `svg/snb-icon-transparent.svg` — standalone transparent icon
- `svg/snb-icon-light.svg` — icon on white
- `svg/snb-icon-dark.svg` — icon on midnight navy
- `svg/snb-monochrome-black.svg` — black one-colour lockup
- `svg/snb-monochrome-white.svg` — white one-colour lockup
- `svg/favicon.svg` — compact browser icon

## Brand colours
- Midnight Navy: `#080D16`
- Ink: `#0B1424`
- Electric Blue: `#168BFF`
- Cyan: `#38BDF8`
- White: `#FFFFFF`
- Slate: `#536174`

## Typography
Recommended: **Inter** or **Montserrat** for the wordmark and interface. The SVG uses a font stack (`Inter, Montserrat, Arial, sans-serif`); for exact output across systems, convert text to outlines in a vector editor after final approval.

## Usage
- Use the transparent primary lockup on uncluttered light or neutral backgrounds.
- Use the dark lockup on dark surfaces.
- Keep clear space around the logo at least equal to the height of the monogram's cyan terminal dot.
- Do not stretch, skew, recolour arbitrarily, add heavy shadows, or place the mark over busy imagery.
- For small UI placements, use the standalone icon rather than shrinking the full wordmark.

## Website integration
Copy the chosen SVG into your site's `assets/images/` folder. Example:

```html
<a class="brand" href="/" aria-label="SNB Technologies home">
  <img src="assets/images/snb-primary-transparent.svg"
       alt="SNB Technologies — Engineering Beyond Limits">
</a>
```

```css
.brand img {
  display: block;
  width: min(260px, 100%);
  height: auto;
}
```

These are vector-first working assets. Review the visual at intended sizes before production print use; the type in the SVG is live text rather than outlined lettering.
