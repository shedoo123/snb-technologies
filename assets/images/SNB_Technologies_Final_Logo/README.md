# SNB Technologies — Final Logo Assets

Brand name: SNB Technologies
Tagline: Engineering Beyond Limits.

## Design concept
The logo uses a custom angular SNB monogram with no enclosing frame. A sweeping orbital line conveys motion, exploration and systems thinking. Three circuit terminals reference engineering and connected technology without turning the mark into a generic circuit-board badge.

## Website integration
Copy the preferred SVG into `assets/images/`, then use:

```html
<img src="assets/images/snb-primary-dark.svg"
     alt="SNB Technologies — Engineering Beyond Limits">
```

Use `snb-primary-dark.svg` on a dark background and `snb-primary-light.svg` on white. Use `favicon.svg` as the browser favicon:

```html
<link rel="icon" type="image/svg+xml" href="assets/images/favicon.svg">
```

SVG artwork is vector-based and scales without pixelation. Wordmark text is live SVG text; for print-production consistency, convert text to outlines in a vector editor after final approval.
