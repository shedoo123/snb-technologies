PROJECT 01
⌁ RFID ACCESS CONTROL ARDUINO • RC522 • SERVO
Completed Prototype Embedded Systems

RFID-Based Access Control System

An Arduino-based access control prototype that uses RFID identification to control a servo-operated locking mechanism.

Core Components

  • Arduino
  • RC522 RFID Reader
  • Servo Motor
  • 16×2 LCD
  • Barrel Bolt Latch

Implementation Highlights

The system reads RFID card identifiers, checks authorized UIDs, and controls the locking mechanism. The prototype was mounted on a wooden demonstration board.

PROJECT 03
▣ 2D GAME DEVELOPMENT C++ • RAYLIB
Learning / In Progress Software Development

C++ 2D Game Development

A C++ and raylib-based 2D platform game in which a ball continuously falls and bounces between a player-controlled platform and the top and side boundaries of the game screen. The player must keep the ball in play. Missing the platform triggers a Game Over state.

Gameplay Features

  • Ball Physics
  • Collision Detection
  • Platform Interaction
  • Score Tracking
  • Pause / Resume
  • Game Over State
  • Restart with Enter
  • Pause with Space
